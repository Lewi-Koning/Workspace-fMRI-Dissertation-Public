# The series of python scripts used within the study

Scripts include:
- Script produced by Dr Denis Schluppeck containing numerous functions used within the **Neuroarch_MRI_Exp** script - **Compatability.py**
- Self assessment manikin task script used to gather behavioural data - **Neuroarch_Behav_Exp.py**
- Script used in the MRI sessions that displayed the video stimuli and fixation task to participant - **Neuroarch_MRI_Exp.py**
- Script that produced the saliency analysis maps using DeepGaze IIE made by ChatGPT - **create_video_saliency_maps.py**

As well as a folder **Behavioural_Exp_Components** containing the human manikin images used within the **Neuroarch_Behav_Exp.py** script
